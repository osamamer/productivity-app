# Mobile frontend

This directory contains the Expo/React Native client. Keep it API-compatible with the authenticated web client and use `EXPO_PUBLIC_*` variables for public origins and client identifiers only; never place a Keycloak client secret in the bundle.

Use `src/providers/ThemeProvider.tsx` as the source of visual tokens, `src/services/api.ts` for backend calls, and `src/types/models.ts` for transport shapes. New protected screens belong under `src/app/` and must be declared inside the authenticated `Stack.Protected` group in `src/app/_layout.tsx`. Native navigation owns page transitions; `Screen` must not replay a whole-page animation on focus. Stable page reads use `src/lib/pageCache.ts` through keyed `useAsyncData` snapshots (one-day ceiling, date/route-scoped keys); API writes invalidate snapshots and logout clears them. Active sessions reconcile with the server on entry and while active; Meditation can render the prefetched session snapshot while that check runs silently. Opening Mind warms threads, mental-state history, the active meditation session, saved meditation settings, and current-month practice statistics. The Meditation screen and practice calendar share date-scoped statistics snapshots, invalidated by meditation/stat writes.

Use `src/providers/PopupProvider.tsx` and `src/components/ui/AppPopup.tsx` for confirmations, errors, and reminder fallbacks; do not use React Native system alerts. Date and time fields should keep their selection UI inside the themed popup. Task priority controls use `src/lib/taskPriority.ts` for the web client’s Low/Medium/High colors and thresholds. Calendar task items stay neutral and show their assigned calendar color only on the left edge.

`src/lib/taskDetailsCache.ts` owns the one-day in-memory task details cache, including subtasks and recurrence. Prefetch task rows and visible calendar items with its four-request concurrency limit, update cached details through the API service, and clear the cache when the authenticated session ends.

For mobile scheduling controls, use a `Custom` action that opens the themed date/time popup. Do not leave a `Someday` action that silently means “no date”; keep custom selection and cancellation behavior explicit.

Run `npm run lint`, `npm run typecheck`, and `npm run export:android` before handing off mobile changes. OAuth must be tested in a native development build because Expo Go cannot register the `solife` callback scheme.

Home reserves the pull-to-refresh indicator for explicit refresh gestures; background reconciliation stays silent. Task rows are transparent except during selection or drag, and expanded task groups use an internal left rail below the expand arrow, alongside indented children; collapsed groups have no rail. Long-press selection must also work on rows where dragging is disabled (including leftovers and stat groups). Notes seed their editor snapshot before navigation and show editable fields only after the matching draft is hydrated. Home shows a group with only one task left (one in the list, or one not yet done) as that task alone, hiding its done tasks (the Tasks tab keeps the group, as on the web), and groups open and close with `components/ui/Collapsible`, which keeps the tasks mounted (hidden with `display: 'none'`) and animates with `LayoutAnimation` via `animateCollapse()`; don't animate a measured height, which on device arrives late and lets the group draw over the rows below. Boundaries screens are readable while locked, with a Today status of every limited app; edits need the unlock password, whose authorization lasts ten minutes in memory across navigation/backgrounding (`useBoundariesAccess`) and is cleared on logout.

Calendar supports saved day/week/month views. Day view uses device-local hourly placement, clips overnight events to each day, and gives overlapping timed items separate columns with an eight-pixel gap; the timeline explains that these are simultaneous items and labels each item by kind; all-day events and tracking have separate labeled sections. Calendar management uses the shared bottom sheet with one scroll container. Task details schedule through one When row (`src/components/tasks/when/`): a sheet with Date and time and Repeat tabs, saved on Done. For an existing series, a changed date, time or reminder asks "This occurrence" or "All occurrences"; all-occurrence time changes keep the series' first date unless the date changed too, then refresh occurrences from the server so historical/completed timestamps stay intact. Rules and change detection live in `frontend/shared/repeatRule.ts` and `frontend/shared/whenDraft.ts`, shared with the web.

For phone testing, use `build-production-apk-to-drive.sh` rather than sharing debug APKs. It stamps a production APK with the commit-based Android build code (plus one for uncommitted previews), includes that code in the filename, and shares it to the paired phone. The native version-name plugin already adds the code; keep Expo’s app version at the baseline to preserve OTA runtime compatibility.
