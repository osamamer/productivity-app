# Meditation audio

These files are local copies of public-domain recordings from Wikimedia Commons.
They are trimmed and converted to mono MP3 for use as bundled meditation soundscapes.

- `rain.mp3`: [Rain.ogg](https://commons.wikimedia.org/wiki/File:Rain.ogg), released to the public domain by ジダネ.
- `ocean.mp3`: [Waves.ogg](https://commons.wikimedia.org/wiki/File:Waves.ogg), released to the public domain by Dsw4.
- `forest.mp3`: [20090610 0 ambience.ogg](https://commons.wikimedia.org/wiki/File:20090610_0_ambience.ogg), released to the public domain by nille.
- `bowls.mp3`: [SingingBowl1.ogg](https://commons.wikimedia.org/wiki/File:SingingBowl1.ogg), released to the public domain by BambooBeast.
